# Security

Report vulnerabilities to [support@qorlie.com](mailto:support@qorlie.com) with the subject line **Security**. Include enough detail to reproduce the issue (URLs, request IDs, timelines).

Policy and supported versions: [qorlie.com/en/docs/security](https://qorlie.com/en/docs/security)

Machine-readable contact: [qorlie.com/.well-known/security.txt](https://qorlie.com/.well-known/security.txt)

This repository holds docs and connection info for Qorlie's hosted remote MCP server. It does not contain product source code or secrets.
